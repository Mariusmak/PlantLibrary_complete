## 4. Facts K-1 copies verbatim (so the spec does not re-derive them)

- **Pattern:** `^(PROPOSAL|PROMPT|PROMPTS|PLAN|EVIDENCE|AUDIT|REGISTER|MATRIX|SNAPSHOT|HANDOVER|FINDING)_.+_\d{4}-\d{2}-\d{2}\.md$`;
  handover variant `^(HANDOVER|FINDING)_.*\d{4}-\d{2}-\d{2}.*\.md$`. `topic` is lowercase, hyphen-separated, no type word;
  compliant uppercase/compound topics in existing names are accepted — no case churn.
- **Proof-surface detectors:** `pytest(?:\s+\S+)*?\s+tests/?(?:\s|`|$)`; `(--ignore=|(?<=\s)-x(?=\s|`|$)|--lf\b|--ff\b)`;
  `(re)?run (the )?(full|whole|entire)( non-gui| offline)? suite|(full|whole|entire) suite to completion` (case-insensitive)
  with the negation guard `\b(do not|don't|never|not|no|forbid|prohibit)\b` applied to the text before the match; `-k` legal;
  the sanctioned launcher's lines exempt; `handovers/` never scanned.
- **Index line:** `- YYYY-MM-DD · <file> · <TYPE> · <status> · <summary>`; mapping table `| old name | new name |` with held
  rows `**held** — cited by <citer>. Target on release: <new name> (date divergence: git-created <date>)`.
- **Decision id:** `D-YYYY-MM-DD-nn`, `nn` two digits, unique per day, next free id verified by grep before writing.
- **Frozen-set discipline:** an exemption or held set "grows or shrinks only via an explicit decision, never silently"; the
  decision is cited in a comment next to the change (row 7's own rule) or in the decision record.
- **Baseline for K-3:** over SOURCE's `implementation/Conductor_V2` at `fc5a14c` the kit's checker must report zero
  violations across `planning/` (root), `proposal/`, `handovers/`, with the four exempt names and the two held names above
  honoured, and the proof-surface scan must report zero violations over the `PROMPT_*`/`PROMPTS_*` corpus (≥ 20 files) — the
  same verdict as the 11 green nodes; a deliberately non-compliant scratch tree (an undated file in a root, a `PROMPT_` file
  with `pytest -q tests`, a `CLAUDE.md`/`AGENTS.md` pair whose marked blocks differ by one byte) must fail with the file
  named. Line count of the checker is not a target; its dependency set is: stdlib only.
