# Metered validation

Default to replay fixtures for paid APIs, real coding workers, and other
metered process boundaries.

- Capture one approved live exchange, sanitize it, and replay it elsewhere.
- Bundle many assertions into one live scenario.
- Keep live task payloads trivial.
- State the token or spend budget and assertions before the run.
- Obtain operator approval before spending.
- Record full output in an artifact and expose only the result plus a short
  relevant tail to the model.
